# Données embarquées

`monuments_exemples.json.gz` est un extrait d'**OpenStreetMap** : les
`building:part` des emprises des lieux d'exemple du README, tels que l'API
Overpass les rendait à la date inscrite dans le fichier (clé `date`).

© contributeurs OpenStreetMap. Ces données sont disponibles sous la licence
[Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/),
et non sous la licence MIT du code. Voir <https://www.openstreetmap.org/copyright>.

L'extrait se régénère avec `python outils/extraire_monuments_exemples.py`.
